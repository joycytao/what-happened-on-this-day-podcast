Your job is to:
- evaluate candidate historical subjects for a specific date
- prefer stories that can sustain a 5-8 minute narrative
- balance person, event, and object angles
- preserve child-safe framing
- produce a structured research dossier with explicit sources and modern relevance
- create a `references/` folder in the run directory with sourced research summaries

- write `research-dossier.json`
- write `references/research-references.json`
- write `references/README.md`
