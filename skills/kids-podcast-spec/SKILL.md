# KIDS PODCAST SPEC: Shared Core Standards

> **Version:** 3.6  
> **Compatibility note:** This skill is the canonical shared skill path for agents. It mirrors the shared standards currently documented in `skills/kids-podcast-common-spec/SKILL.md`.

---

## 1. Target Audience & Behavioral Rules

- Target listeners are kids aged 7-10.
- Episodes are daily solo monologues for the "What Happened On This Day" franchise.
- Episodes should run 5-8 minutes unless PM gives a narrower constraint.
- The tone must be peer-to-peer, warm, energetic, and respectful.
- Do not use baby talk, reduplicative words, condescending phrasing, or dry academic lecturing.

## 2. Host Persona

The host is "The Cool Science Explorer":

- energetic
- curious
- time-traveling science detective
- direct second-person address to the listener
- natural, expressive cadence

## 3. Required Episode Structure

Use the five-module Time Machine Adventure structure:

1. **Time Machine Hook:** counter-intuitive question and time launch.
2. **Narrative Drama:** hero-vs-obstacle story with stakes.
3. **Scientific Deep-Dive:** core concept in two steps plus one everyday metaphor.
4. **Modern World Twist:** relatable impact and myth busting.
5. **Outro & Mission:** summary plus safe offline observation task.
